# showntell

Narrated slide walkthroughs for coding agents, voiced on your machine.

Your agent writes slides and narration in Markdown. showntell voices them locally with Kokoro and gives back a link that starts playing within a second or two, while the rest is still being written.

Work in progress: see [ROADMAP.md](ROADMAP.md), the [format](docs/format.md) and the [spec](docs/spec.md).
